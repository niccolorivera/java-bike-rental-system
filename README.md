# Java Bike Rental System

## Descrizione
Sistema sviluppato in Java per la gestione di un servizio di noleggio biciclette, basato su principi di programmazione a oggetti.

Il progetto simula la gestione di biciclette, utenti e noleggi, utilizzando classi, ereditarietà e collezioni.

---

## Funzionalità principali
- Gestione biciclette
- Differenziazione tra tipologie (elettriche, non prestabili)
- Gestione utenti (persone)
- Sistema di noleggio
- Ordinamento e gestione dati tramite collezioni Java

---

## Tecnologie utilizzate
- Java
- Programmazione a oggetti (OOP)
- Collezioni Java (List, Map, Set)
- Comparator per ordinamenti

---

## Struttura del progetto
- `Bici.java` classe base
- `BiciElettriche.java` estensione con funzionalità specifiche
- `BiciNonPrestabile.java` gestione casi particolari
- `Persona.java` gestione utenti
- `Noleggio.java` logica noleggio
- `Main.java` esecuzione programma

---

## Esempio utilizzo
Il sistema consente di:
- creare utenti
- registrare biciclette
- effettuare un noleggio
- visualizzare dati organizzati
